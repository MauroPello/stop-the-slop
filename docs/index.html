Workflow

How Detection Works

A seamless three-step pipeline designed for speed, accuracy, and lightweight browser performance.

01

Extract Transcript

When you load a YouTube video, the extension non-intrusively extracts official or auto-generated subtitle tracks directly from the page.

02

Edge AI Evaluation

The transcript is analyzed via our fast Cloudflare Worker API to detect typical LLM stylistic markers, sentence perplexity, and repetitive filler formulas.

03

Instant In-Page Score

You receive an intuitive probability gauge and an itemized breakdown of flagged sentences in the extension popup and on-screen badge.

FAQ

Frequently Asked Questions

Is Stop the Slop 100% free? +
Yes! Stop the Slop is 100% free, open-source under the MIT license, and contains no ads or paywalls.
How accurate is the AI detection score? +
Detection is powered by advanced AI linguistic analysis via Sapling AI and heuristic pattern detectors. While it provides strong indicative probabilities of LLM-generated phrasing, results are advisory rather than 100% conclusive.
What data does the extension collect? +
Zero personal data is collected. The extension only reads the video ID and transcript on the YouTube watch page you are currently viewing to perform the analysis. See our Privacy Policy for full details.
Does it work on videos without subtitles? +
The extension requires a transcript to analyze. It works seamlessly with both manual creator subtitles and YouTube's auto-generated captions. If a video has all captions disabled, analysis cannot be performed.
