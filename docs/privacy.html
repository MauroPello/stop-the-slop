Privacy Policy

Last Updated: August 2026 · Applies to: Stop the Slop Extension
Summary: Stop the Slop is an open-source project. We do not collect personal identification, user accounts, browsing histories, IP tracking logs, or cookies. The extension only reads public YouTube video transcripts to calculate script probability scores.

1. Information We Process

To perform script detection, the extension extracts the publicly accessible transcript or subtitle track of the YouTube video currently open in your active tab.

  • YouTube Video ID and Transcript: Sent to the backend analysis endpoint to calculate linguistic AI probability scores and highlight repetitive patterns.
  • No Personal Data: We do not collect names, email addresses, IP addresses, search queries, browsing history outside of YouTube, or Google account information.

2. Browser Permissions

When installing the extension, your browser may prompt you about the following permissions:

  • tabs / activeTab: Used strictly to check if the currently focused browser tab is a YouTube video URL (e.g. youtube.com/watch?v=...) and retrieve its video ID.
  • storage: Used locally on your device to store your theme preferences (dark, light, system) and cache recent analysis scores to minimize repeated network calls.
  • scripting and host_permissions: https://www.youtube.com/*: Required to inspect captions and render thumbnail probability badges directly on the YouTube video interface.

3. Third-Party Services

The extension communicates with a lightweight backend service hosted on Cloudflare Workers:

  • Linguistic Analysis: Transcripts are evaluated against language model markers to detect text uniformity and formulaic phrasing.
  • Caching: Analysis scores are cached anonymously by YouTube Video ID in Cloudflare D1 to speed up response times and reduce server load. No user identifiers are associated with cached results.

4. Data Sharing and Monetization

We do not sell, rent, monetize, or trade any user data to third parties, advertisers, or data brokers. The extension is free and open-source under the MIT license.

5. Open Source Transparency

The entire codebase for the browser extension and backend worker is public. You can inspect, audit, or verify the exact code running in the extension on our GitHub repository.
