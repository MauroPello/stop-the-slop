- **Direct URL**: https://news.ycombinator.com/showhn.html
- **Title**: `Show HN: Stop the Slop – Detect AI-generated YouTube scripts and content farms`
- **URL**: `https://github.com/MauroPello/stop-the-slop` (or `https://mauropello.github.io/stop-the-slop/`)
- **First Comment / Submission Text**:
```markdown
Hi HN! I built Stop the Slop, a free and open-source (MIT) browser extension for Chrome and Firefox that detects whether YouTube video scripts were generated with AI.

Like many of you, I've noticed YouTube search and recommendations increasingly clogged with low-effort AI content farm videos—often using recycled ChatGPT scripts paired with synthetic voiceovers and stock footage.

How it works:
1. When browsing YouTube, the extension fetches public caption tracks non-intrusively in MAIN world context.
2. The transcript is sent to a Cloudflare Worker that queries Sapling AI's detection model alongside local heuristic pattern detectors (repetitive introductory formulas, robotic transitional phrases, perplexity indicators).
3. We cache video verdicts on Cloudflare D1 edge database. As a result, when you scroll your Home feed, Subscriptions, or Search, the extension batch-fetches cached verdicts and displays instant AI probability badges on video thumbnails (<50ms).
4. Opening the extension on any video gives you an in-depth sentence-level heatmap showing exactly which lines triggered the score.

Privacy & Design:
- Zero user tracking, zero telemetry, no accounts or signups required.
- Manifest V3 compliant for Chromium (Chrome, Brave, Edge) and Mozilla Firefox.
- 100% open source under MIT.

Repo: https://github.com/MauroPello/stop-the-slop
Interactive Demo & Site: https://mauropello.github.io/stop-the-slop/

Firefox Add-on: https://addons.mozilla.org/en-US/firefox/addon/stop-the-slop-ai-video-detect/

I'd love your feedback on the heuristic scoring, edge architecture, and false-positive handling!
```

### 4.3 Indie Hackers
- **Direct URL**: https://www.indiehackers.com/products (or post in /post)
- **Title**: `I built an open-source tool to detect AI slop on YouTube — here's how it works`
- **Post Body**:
```markdown
Hey Indie Hackers!

Over the last few months, YouTube feeds have seen an explosion of low-effort "faceless" AI content channels: automated scripts from LLMs, cloned voiceovers, and stock b-roll stitched together for ad revenue.

I wanted a way to know before clicking whether a video was made by a real human creator or generated in bulk. So I built **Stop the Slop**, a free, open-source browser extension.

### The Tech Stack
- **Frontend**: Vanilla JS + CSS (Manifest V3) for Chrome and Firefox.
- **Edge API**: Cloudflare Workers + D1 Database for global batch caching.
- **AI Detection**: Sapling AI API combined with custom regex heuristic filters for common LLM transition patterns.
- **Hosting**: GitHub Pages with an interactive simulator so users can test before installing.

### Key Learnings
1. **Performance is king**: Users won't wait 3 seconds on a YouTube feed. By batch-querying Cloudflare D1 for video IDs already analyzed by the community, thumbnail badges load in under 50ms.
2. **Explainability matters**: A single percentage number isn't enough. Providing a sentence-by-sentence breakdown builds trust and shows users *why* something was flagged.
3. **Privacy first**: Making it completely account-free with zero telemetry eliminates friction and builds genuine goodwill in the developer community.

Links:
- Website & Live Demo: https://mauropello.github.io/stop-the-slop/
- Chrome Web Store: https://chromewebstore.google.com/detail/stop-the-slop-%E2%80%94-ai-script/afifehnicpeokjjhpbicikfoalkemelg

- GitHub (MIT): https://github.com/MauroPello/stop-the-slop

Happy to answer any questions about building Manifest V3 extensions or edge-cached APIs!
```
